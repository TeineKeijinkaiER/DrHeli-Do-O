# 道央ドクターヘリ 判断支援アプリ（公開・安全版）

機密情報を含まない公開PWAです。収録モードは、地図・ベーシック・インベントリー・クイズの4つです。

## 更新方法

このリポジトリを直接編集しません。非公開の正本リポジトリ `DO-O/pwa/` を更新し、DO-O側で次を実行します。

```bash
node scripts/build-public.mjs --write
```

許可リストに含まれるファイルだけが同期されます。患者・運航原データ、リフレクション、統計、管理画面、利用履歴はこの公開版に含めません。

## ローカル確認

Windowsでは `起動.cmd` を実行し、表示されたローカルURLを開きます。`index.html` の直接起動ではデータを読み込めません。
